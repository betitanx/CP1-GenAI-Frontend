# Roteiro de demonstração

Duração sugerida: dois a quatro minutos. Configure a chave OpenAI no `.env` antes de gravar. Não mostre esse arquivo durante a gravação.

1. Mostre o nome do projeto e a seção de integrantes no README do GitHub.
2. Mostre os terminais com FastAPI na porta 8000 e Streamlit na porta 8501.
3. Abra a interface e processe os documentos de exemplo. Mostre a contagem e expanda um documento para visualizar chunks diferentes com identificadores de origem.
4. Ative uma persona, como “Estudante: busca explicações didáticas”, e salve. Gere três perguntas. Mostre o texto das perguntas e as fontes registradas.
5. Execute as perguntas no RAG. Abra a aba Avaliação e expanda um item para mostrar resposta e contextos recuperados.
6. Clique em Avaliar respostas. Mostre as três médias, a tabela individual e as justificativas do juiz.
7. Baixe o JSON e mostre que pergunta, contextos, resposta e métricas estão preservados.
8. Finalize mostrando a URL do repositório. Salve a gravação como `demonstracao.mp4` e entregue junto ao link do projeto.

Não apresente respostas simuladas dos testes como resultado de uma LLM real. Se a OpenAI retornar erro de chave ou saldo, corrija a configuração antes da gravação final.
